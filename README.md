# Cable-Driven Rope Robot

**Python · kinematics · robotics**  
**Course:** University of Alberta · Robotics & AI

## Overview

Experimental Python coursework related to a four-cable, two-dimensional robot: kinematics, trajectory control and robot GUI. The full hardware setup also used motors and camera-based ball tracking.

## Project files

- `robotics/ropebot_gui.py` — original robot GUI source.
- `robotics/kintest.py` — original kinematics test code.
- `ev3-labs/` — original EV3 practical exercises on motion and sensors (group coursework).

## Running the project

The Python scripts depend on the original robotics hardware/software environment and are not a standalone working robot simulation.

## Provenance

This repository preserves **original university coursework source files**. The interactive browser adaptations in the portfolio were built later and may use different implementations. No current build or hardware compatibility is guaranteed.

**Team project:** robot hardware and final integration were completed as a group; the scripts here are surviving source files and do not represent the entire system.
